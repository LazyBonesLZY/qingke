## 改动

- 统一 `APP_TIME_ZONE = Asia/Shanghai`，当前日期、毫秒转日期、课表钟点转时间戳和选课时间输入/输出均使用北京时间。
  继续以设备时钟提供当前时刻，没有修改系统时区、系统时钟或接入网络校时。
- Android 16 的 compact Live chip 恢复分钟倒计时文字；展开内容继续使用系统 chronometer。
  分钟文字仍由应用/服务刷新，冻结后的更新与厂商实际展示需真机验证。
- 保留 `liveCountdownEnabled` 序列化字段，但含义改为「上课胶囊与通知」总开关。
  关闭后清除测试窗口、撤销 Android 课程通知、停止前台刷新服务、取消 Live 闹钟，并请求结束私有任务。
- 通知构建、统一发送、服务启动、闹钟调度和 OPPO 异步回调均检查当前总开关，防止旧帧恢复已关闭的提醒。
- 完整快照采用异步保存；关键开关额外立即保存到 `qingke-live-enabled`，启动和后台冷读时合并该选择，
  避免快照尚未写完就结束进程后恢复旧状态。该文件使用原有平台存储实现，Android 使用 AtomicFile。
- 隐藏周末时以七列布局的单日宽度计算五列卡片宽度并居中；显示周末仍使用原有完整宽度，月历保持七天。

1.8.2 及更早记录中的「倒计时关闭后显示静态状态」仅描述当时版本；本版本关闭该开关后不再发送课程通知。
厂商业务配置、授权要求、有限重试与异步请求失效机制继续沿用上一版本。
